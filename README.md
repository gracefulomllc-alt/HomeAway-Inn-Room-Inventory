# Home Away Inn — Room Survey

Live app: https://homeaway-room-survey.netlify.app
Handyman view: https://homeaway-room-survey.netlify.app/?view=handyman

- `public/index.html` — the app (single file)
- `netlify/functions/sync.mjs` — shared sync between phones (Netlify Blobs)
- `tests/` — run `sh tests/run-all.sh` before every change

Every push to `main` deploys automatically on Netlify.
